# Architecture

The Marketing Starter Template is a Next.js app that reads content from Contentful's GraphQL Content API and renders it as a website. Content editors work in Contentful, and the app fetches published content (or draft content in preview).

## Stack

- Next.js Pages Router (`src/pages`), React and TypeScript.
- Material UI for styling and components.
- `next-i18next` for localisation. Locales come from the Contentful space.
- `@contentful/live-preview` for live updates and inspector mode in the Contentful web app.

## Layout

- `src/components/` holds UI, split into `features/`, `shared/` and `templates/`.
- `src/lib/` holds the GraphQL queries and fetch helpers. `src/lib/serverFetchConfig.ts` picks the delivery or preview token on the server, and `src/lib/__generated/` holds the typed code generated by GraphQL Code Generator.
- `src/pages/api/contentful.ts` proxies GraphQL requests to Contentful so API tokens stay on the server.
- `next.config.js` limits the image optimizer to an allowlist of Contentful image hosts.
- `sentry.*.config.js` set up error reporting, and `analytics/` holds the Segment tracking setup used by the hosted demo.
- `bin/` and `docs/tutorials/` support the guided setup described in `README.md`.

## Data flow

Pages fetch data with React Query. Requests go through `src/pages/api/contentful.ts`, which calls Contentful's GraphQL API with the delivery token, or the preview token for preview requests.
